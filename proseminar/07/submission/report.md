# Task 1
### DISCLAIMER:
 Implementation only works when all tasks are on one node or when not more than one tasks runs on one node. Otherwise, the code results in segmentation faults produced by `Openfabric` or the `Infiband`. It's unclear to us what causes this since **NO** `MPI`-function used for communication throws an error. To verify this all communication related function are wrapped in an error checker.

 Debugging was done using sanitizers for addresses and the `MUST` tool. Both without affect since the sanitizers referred to read/write operation by `MPI` intern functions to a `nil` address. The output of `MUST` once indicated a mismatch between communication calls, which is somehow the point when using RMA. Another time nothing at all was reported, neither that the program worked not that it failed. (*Spoiler: It failed.*) 


### Implementation:
 We used our naive parallel implementation from the last exercise sheet and replaced the `MPI_AllGather(...)` calls with `MPI_Get(...)` calls inside of windows guarded by `MPI_fence(...)`. 

 For initialization, we used one window to exchange the position for particles generated by each rank and one for exchanging the randomly generated mass. In the first iteration we used layered windows and the two `MPI_Get(...)` calls where called inside one for loop over all participating ranks.

 After each computation loop an exchange of the total forces for each particle is done. Using a window and a `MPI_Get(...)` inside a loop over all ranks.

 Since we suspected the error here we introduce a `MPI_Barrier(...)` call before we enter the communication section of each time step, without effect.
